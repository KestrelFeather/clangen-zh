# ClanGen 中文试玩 alpha.5 · 月度推进崩溃修复

这是针对 alpha.4 严重错误的修复版。请使用本版替代 alpha.4。感谢玩家提供中文与英文对照测试和精确的崩溃位置。

## 修复内容

- 短事件（包括伤病）、族长巢穴外交事件、持续灾难事件统一使用语言资源加载器。中文文件不存在或 JSON 无法解析时，回退到英文文件；不再因缺少尚未翻译的事件资源而中断月份推进或外交结算。
- 英文回退文件本身缺失或损坏时保留明确错误，不把资源缺失伪装成正常的空事件列表。
- 短事件缓存区分当前语言和回退语言，切换语言不再复用另一种语言的事件对象。
- 同窝手足判断使用亲属计算生成的布尔标记，不再用英文 `litter mates` 匹配中文说明。亲属提示仍显示中文，判定不受切换语言影响。
- 上游英文名字断言仅在英文模式下运行；中文名字继续由专项测试验证。JSON 模型测试明确使用 UTF-8，避免 Windows 系统编码影响结果。

## 验证流程修正

此前 alpha.4 的中文专项测试和单个月份离屏测试不足以覆盖实际事件分支，遗漏了这些发布阻断问题。构建入口现改为必须运行中文、英文两套完整测试；每套均包含 500 个月的连续推进。新增的直接加载测试覆盖短事件资源、外交成功/失败、持续事件、语言切换、文件缺失及 JSON 损坏，避免只依赖随机月度流程。

打包程序探针增加实际外交结算、连续推进及推进后保存读档。实际结果和边界见 [验证记录](https://github.com/KestrelFeather/clangen-zh/blob/v0.13.4-zh.0.1.0-alpha.5/localization/VALIDATION.zh-CN.md)。

## 下载与更新

完整解压 Windows x64 ZIP 到新文件夹，运行 `ClanGenChinese.exe`，保留 `_internal` 文件夹，无需安装 Python。校验文件为附件 `SHA256SUMS.txt`。

继续使用中文版本原有的 `%LOCALAPPDATA%\KestrelFeather\ClanGenChinese` 数据目录，更新前请备份。修复不改变存档字段或随机事件规则，不追溯重算此前已经发生的事件筛选结果。如果崩溃前的进度没有保存，仍需从最近一次有效存档继续。

本版保留 alpha.4 已完成的名字、资料健康和管理界面汉化。大量月度事件、巡逻叙事、思想和未确认名字仍回退英文；修复回退不代表这些内容已翻译。
