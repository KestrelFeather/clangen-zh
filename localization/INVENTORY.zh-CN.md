**字符串值包括内部 ID、条件标签、语言配置和重复内容，不等于待翻译句数。**
例如 `events/death/general.json` 的 `event_text` 是显示文本，但同一条记录的 `event_id`、`season`、`m_c.status` 属于游戏逻辑数据。
巡逻数据同样混合 `intro_text`、`decline_text`、结果文本、巡逻 ID、概率和条件。

后续翻译导出必须按具体 schema 筛选显示字段，不能把这份原始盘点直接交给批量翻译器回写。
当前没有统计代码硬编码文本、图片内文字和目录之外的命名资源，也没有声称中文覆盖率。

## 初步工程结论

- 稳定版已有语言加载与语言选择代码，可先验证复用。
- 资源加载的文件级回退与 i18n 的字符串回退是两个机制，需要分别测试。
- 当前字体注册为 NotoSans 和 clangen；中文字符覆盖、图标兼容和视觉表现尚待验证。
- 打包版目前使用原版 ClanGen / ClanGenBeta 数据目录，需要为中文发行版隔离。
- 首页更新检查包含官方 upstream 身份条件，正确填写 fork 身份是必要条件；仍需完成实际打包验证。
- 继承的构建脚本包含官方 API 和 itch.io 发布目标。新 fork 已暂停 Actions，独立构建流程完成后再启用。
- 本轮未运行游戏或构建 EXE；文本工具验证不能代替游戏与打包验证。
